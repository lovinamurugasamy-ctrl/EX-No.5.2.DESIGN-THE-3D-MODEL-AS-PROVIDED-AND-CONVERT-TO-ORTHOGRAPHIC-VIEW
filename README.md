# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

Part 1 – Create the tabletop
Step 1: Create a new design
1. Open Autodesk Fusion 360.
2. Click File → New Design.
3. Click Create Sketch.
4. Select the XY plane.
Step 2: Draw the tabletop
1. Select Rectangle → 2-Point Rectangle.
2. Draw a square at the origin.
3. Press D (Sketch Dimension).
4. Set the length to 30 mm.
5. Set the width to 30 mm.
6. Click Finish Sketch.
<img width="340" height="373" alt="Screenshot 2026-11-24 191900" src="https://github.com/user-attachments/assets/23568474-cf30-455a-8454-e903794425b5" />

Step 3: Extrude the tabletop
1. Press E (Extrude).
2. Select the square profile.
3. Enter 4 mm thickness.
4. Select New Body.
5. Click OK.
Your tabletop is completed.

Part 2 – Create the table leg
<img width="337" height="376" alt="Screenshot 2026-11-24 192545" src="https://github.com/user-attachments/assets/3729a7c6-6193-43a2-9bc0-c25053fe75c5" />
Step 4: Create the first leg
1. Select the bottom face of the tabletop.
2. Click Create Sketch.
3. Select Rectangle → 2-Point Rectangle.
4. Draw a small rectangle at one corner of the tabletop.
5. Set the leg dimensions to 2 mm × 2 mm.
6. Click Finish Sketch.
Step 5: Extrude the first leg
1. Press E.
2. Select the rectangle profile.
3. Enter 30 mm extrusion length.
4. Select Join.
5. Click OK.
The first leg is ready.
<img width="418" height="202" alt="Screenshot 2026-11-24 192610" src="https://github.com/user-attachments/assets/8d38428f-15f7-4bb9-85ae-752e0a329bbf" />

Part 3 – Create the remaining three legs
Step 6: Draw the second leg
1. Select the bottom face of the tabletop.
2. Click Create Sketch.
3. Draw a rectangle measuring 2 mm × 2 mm at the second corner.
4. Click Finish Sketch.
5. Press E.
6. Select the rectangle.
7. Extrude it 30 mm downward.
8. Select Join.
9. Click OK.
Step 7: Draw the third leg
1. Create another sketch on the bottom face of the tabletop.
2. Draw a 2 mm × 2 mm rectangle at the third corner.
3. Click Finish Sketch.
4. Extrude it 30 mm downward using Join.
Step 8: Draw the fourth leg
1. Create a sketch on the bottom face of the tabletop.
2. Draw a 2 mm × 2 mm rectangle at the fourth corner.
3. Click Finish Sketch.
4. Extrude it 30 mm downward.
5. Select Join.
6. Click OK.
All four table legs are now completed.
<img width="328" height="357" alt="Screenshot 2026-11-24 192641 - Copy" src="https://github.com/user-attachments/assets/359d4786-ceb8-4ff9-97f1-78dd48f22d9f" />

Part 4 – Final finishing
Step 9: Check the model
1. Rotate the model using the ViewCube.
2. Check the tabletop dimensions of 30 mm × 30 mm.
3. Check the tabletop thickness of 4 mm.
4. Check all four legs.
5. Verify the leg dimensions of 2 mm × 2 mm.
6. Verify the leg length of 30 mm.
7. Click File → Save and save the design.
